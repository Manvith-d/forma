Forma: six AI agents that act as a personal trainer, a dietitian and a medication-safety reviewer, grounded in a data pipeline over FDA drug labels, USDA food data, U.S. activity and dietary guidelines and open-access research.

This public demo runs rules-only on a free CPU: plans, calorie targets, safety checks, meals and the live agent view are the same as the full app; summaries and recipe steps use templates instead of the local language model. Please do not enter real health details.

Code, evaluation and how to run it with the local model: https://github.com/Manvith-d/forma
